# EnhancedDynamics
## This mod replaces the stock camera dynamics with a more realistic one.
### **Functionality:**
It enhances the external flight camera by adding smooth physics-based camera inertia, realistic rotational tracking, and dynamic visual feedback during flight, along with subtle lag and G-force motion.

---

### **Configuration:**
To toggle the mod's configuration menu while in game, press F8 (or if it's used by another mod, you can use the numpad + key, or you can change the keybind in the .cfg file).

### **Installation:**
Download the latest release zip file, then extract the folder inside EnhancedDynamics_v1.0.7/Gamedata into your KSP gamedata directory.

**Dependencies:** Harmony. To install it, you can install it from CKAN, or [from github](https://github.com/KSPModdingLibs/HarmonyKSP/releases/tag/2.2.1.0).

# Q&A

- **Does it support other camera mods without conflicts?** 

Yes, it supports cameratools, hullcamVDS, and some other camera mods.


- **What about motion sickness?** 

While making this mod, I was extremely aware of [simulation sickness](https://en.wikipedia.org/wiki/Motion_sickness). The pre-release version of the mod may have contributed to some headaches after prolonged use of intense maneuvers, however this issue has been mitigated and motion sickness should NOT occur. Lots of refinements have been made to overcome this problem, and you should be fine. ***However, 
people with severe vestibular disorders or extreme cybersickness are advised NOT TO LOOK BACK AT THIS MOD.*** If you also start feeling of a glimpse of a headache immediately disable the mod through the config menu.


- **Does it also work while in IVA?**

As of v1.0, no, it does not.


- **Is it strictly supported on a specific camera mode?**

No. It replaces the stock camera dynamics, so it's available on all modes.
